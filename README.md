# itilflow — маршруты этапов для GLPI 11

**[English](README.en.md)** · Русский

Плагин ведёт заявку GLPI по маршруту: этап за этапом, в заданном порядке.
Этап — задача в самой заявке, дочерняя заявка группе отдела или согласование
GLPI. Пока маршрут не пройден, заявку нельзя решить; в конце инициатор заявки
получает решение с результатом или с причиной отказа.

Задача, дочерняя заявка или запрос на согласование создаются, когда маршрут
доходит до этапа, поэтому будущий этап не отметить выполненным раньше времени.
Каждое действие маршрута проверяется на сервере.

Ядро GLPI не меняется: сроки, права, уведомления и согласования остаются
штатными.

![Вкладка «Маршрут этапов» на заявке: этапы с результатами, «Лист согласования», «Схема»](docs/img/ticket-tab-admin.png)

## Возможности

- **Три вида этапа:** «Задача», «Дочерняя заявка», «Согласование».
- **Кто согласует:** пользователи или группы этапа («Любой из группы»,
  «Каждый в группе», «Нужно одобрений, %»), согласующий, которого указывает
  исполнитель заявки, или согласование, которое запросила форма GLPI.
- **Условные этапы:** «Когда выполнять» — по ответам формы, вопросам этапов
  выше и категории заявки; ненужный этап ничего не создаёт.
- **Запуск** по ответу формы, бизнес-правилом или вручную с заявки.
- **Отказ, уточнение, новая попытка:** «Вернуть на уточнение» и «Начать заново
  с этапа…» в той же заявке, история попыток сохраняется.
- **Решение в конце маршрута** — с результатом последнего этапа или причиной
  отказа; принимает его инициатор.
- **Строка готовности:** готов ли маршрут к запуску и чего не хватает — сразу,
  без сохранения.
- **Обзор и перенос:** лист согласования, схема маршрута, отчёт «Узкие места
  маршрутов», экспорт и импорт маршрутов файлом.

## Требования

- GLPI 11.0.x. Проверено на GLPI 11.0.8 с MariaDB и MySQL 8.
- MariaDB или MySQL 8, таблицы InnoDB. Сроки — не позже 19.01.2038.
- PHP — версия, которую требует ваша GLPI.
- Системный cron, который раз в минуту запускает `front/cron.php` GLPI.
- Больше ничего: без composer, npm и внешних сервисов.

Интерфейс плагина — только на русском языке.

## Установка

```bash
tar -xzf itilflow-1.13.1.tar.gz -C /var/www/glpi/plugins/
cd /var/www/glpi
php bin/console plugin:install itilflow --username=<администратор GLPI>
php bin/console plugin:activate itilflow
php bin/console cache:clear
```

Затем включите автоматическое действие `itilflow_status_sync` и выдайте права
на вкладке профиля «Маршруты этапов». Подробно, обновление и откат —
[docs/INSTALL.md](docs/INSTALL.md).

## Ограничения

- Маршрут последовательный: один текущий этап, параллельных этапов нет.
- Дочерние заявки и запуск по ответу формы — только для заявок; у изменений
  и проблем — «Задача» и «Согласование».
- Своих уведомлений нет: работают уведомления GLPI о задачах, заявках,
  согласованиях и решениях.
- Даты позже 19.01.2038 не хранятся.
- Интерфейс только на русском языке.
