# Перенос маршрутов

**[English](TRANSFER.en.md)** · Русский

Маршруты переносятся между установками GLPI файлом JSON — так же, как формы
GLPI 11 («Импорт форм»).

## Что в файле

- Маршруты с этапами, условиями и «Запускать, если».
- Ссылки на объекты GLPI: организации, группы и категории — по полному имени;
  календарь и время до решения — по имени; пользователи — по логину; форма,
  её назначение, этап согласования и вопросы условий.

В файле нет заявок, хода маршрутов и паролей. Не переносятся сами формы GLPI
(у них свой экспорт), бизнес-правила, права в профилях, картинки и файлы
из описания этапа — только текст.

Файл формата 4 читает itilflow 1.13 и новее; файлы прежних форматов он читает
как раньше. Более ранний itilflow файл формата 4 не прочитает.

## Экспорт

**Администрирование → Маршруты этапов:** «Экспорт всех» над списком или
отметьте маршруты и выберите массовое действие «Экспорт». Нужно право
«Чтение»; в файл попадают только маршруты, которые вы видите.

## Импорт

1. «Импорт маршрутов» над списком (права «Создать» и «Обновление») →
   «Выберите свой файл» → «Предварительный просмотр импорта».
2. У каждого маршрута — состояние:
   - «Готов к импорту»; если замены выбраны вручную — «Выбрано вручную: N.»;
   - «Нужно выбрать: N» — выберите замены в «Устранять проблемы»;
   - «Не может быть импортирован» — с причиной;
   - «Маршрут с таким именем уже есть — будет пропущен»; «Создать копией»
     создаст его как «… (копия)».

   Под названием — «Запуск маршрута: …» и, если есть условия, «Вопросы
   запуска: из файла → в выбранной форме» с пометкой у каждого вопроса.
   Корзина убирает маршрут из импорта.
3. **«Устранять проблемы»** — для каждого объекта выберите замену из списка
   GLPI или «-----» (оставить пустым):
   - форма находится сама, если её перенесли импортом форм GLPI; иначе
     выберите её и откройте предпросмотр повторно;
   - назначение формы и этап согласования выбираются всегда вручную: «Выберите
     из списка.»;
   - вопросы условий сопоставьте с вопросами выбранной формы того же вида
     и с теми же вариантами ответа;
   - этапу без группы и пользователя укажите исполнителя.

   Остальные объекты ищутся, как при импорте форм GLPI: по полному имени
   в ваших организациях, должен найтись ровно один. Иначе — объект с тем же
   номером и тем же именем, с пометкой «проверьте». Срок этапа и SLA
   проверяются до импорта: позже 18.01.2038 — не импортируется.
4. **«Импорт»** создаёт маршруты **выключенными**, одной операцией: если что-то
   не записалось, не записано ничего. Существующие маршруты не меняются.

## После импорта

Проверьте каждый маршрут — строку готовности, вкладку «Этапы», «Запуск
маршрута» — и включите его. Маршрут с «Запускать, если» после включения сразу
запускается по ответам формы.

Бизнес-правила, которые запускают маршрут, перенесите штатным экспортом
и импортом правил GLPI: действие «Запустить маршрут этапов» GLPI находит
по имени маршрута. Или заведите правило заново.
