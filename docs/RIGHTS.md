# Права

**[English](RIGHTS.en.md)** · Русский

Плагин добавляет в профили GLPI два права. Остальное берётся у GLPI: доступ
к организации и заявке, назначение исполнителем и согласующим.

## Права плагина

**Администрирование → Профили → ‹профиль› → вкладка «Маршруты этапов».**

| Право | Галочка | Что даёт |
|---|---|---|
| «Маршруты этапов» | «Чтение» | меню «Маршруты этапов», настройки и схема маршрутов, отчёт, экспорт |
| | «Обновление» | администратор маршрутов: настройка маршрутов и этапов, управление маршрутом на заявке |
| | «Создать» | новые маршруты; вместе с «Обновлением» — импорт |
| | «Очистить» | удаление маршрутов и этапов |
| «Закрытие этапа без ответа» | «Закрыть принудительно» | закрыть текущий этап без ответа, с причиной; решить заявку, пока маршрут не пройден, — с записью в «Журнал маршрута» |

- Вкладка есть только у профилей центрального интерфейса. Меняет её тот,
  у кого право GLPI «Профили» на изменение.
- Пункт меню появится после повторного входа.
- При установке «Маршруты этапов» получают профили с «Общими настройками»;
  «Закрытие этапа без ответа» — никто. Обновление права не меняет.

## Кто что может

Каждое действие проверяется на сервере; кнопку видит только тот, кому оно
разрешено. Ни одно право не открывает чужую заявку и не позволяет ответить
за другого согласующего.

| Кто | Что может | Что нужно |
|---|---|---|
| администратор маршрутов | настройка; на заявке — запуск вручную, «Прервать маршрут…», «Возобновить маршрут», «Начать заново с этапа…», «Закрыть принудительно…» у задачи и согласования, «Засчитать согласование» с уже данным ответом | «Чтение» и «Обновление»; право изменения заявки |
| исполнитель этапа «Задача» | «Завершить этап», «Пропустить», «Передать этап…» | профиль центрального интерфейса в организации заявки |
| исполнитель заявки | «Указать согласующего», «Засчитать согласование», «Выполнять этап?», «Продолжить» после уточнения | то же |
| исполнитель дочерней заявки | «Отметить результат», «Ответить инициатору» | профиль в организации дочерней заявки |
| согласующий | «Одобрить», «Отказать», «Вернуть на уточнение», ответы на «Вопросы этапа» и «Сохранить и одобрить» | право GLPI «Утверждения заявок»; хватит самообслуживания |
| инициатор заявки | видеть вкладку, если включена; ответить на уточнение комментарием; «Отозвать заявку», если разрешено | доступ к своей заявке |
| дежурный администратор | «Закрыть принудительно…» любого текущего этапа, в том числе дочерней заявки; решить заявку до конца маршрута | «Закрытие этапа без ответа» |

«Продолжить» нужно, только если уточнение просил исполнитель, согласующий
больше не подходит заявке или инициатор ответил не комментарием. Если вернул
этап согласования, маршрут продолжает публичный комментарий или письмо
инициатора.

Причина обязательна для «Передать этап…», «Закрыть принудительно…», «Указать
согласующего», «Засчитать согласование», «Этап не нужен», «Прервать маршрут…»
и «Отозвать заявку».

С профилем самообслуживания в организации заявки исполнитель не сможет
ни завершить, ни передать этап. Если у пользователя, указанного в этапе
«Дочерняя заявка», нет профиля в её организации, дочерняя заявка
не создаётся.

## Право GLPI на согласование

Отправляя запросы сам («Задан в этапе», «Указывает исполнитель заявки»),
маршрут проверяет каждого согласующего: учётная запись активна, есть профиль
в организации заявки с правом «Утверждения заявок» (вкладка «Поддержка»).

- Без права пользователь в запросы не попадёт — если нет действующего
  заместителя с этим правом.
- Группе «Любой из группы» хватит одного участника с правом.
- Строка готовности называет согласующих, которые проверку не прошли.

Ответить может тот, кому GLPI адресовал запрос: согласующий, участник группы
или действующий заместитель.
